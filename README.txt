# IPL Franchise Explorer

## Files
- index.html -> Website structure
- style.css -> Website design and responsive layout
- script.js -> Team data and click functionality

## How to run
1. Extract the ZIP file.
2. Open `index.html` in Google Chrome.
3. Click any IPL team.
4. The trophy information and player list will appear.

## Viva explanation
HTML creates the structure of the website.
CSS gives the website its layout, cards, colors and responsive design.
JavaScript stores team information in an array and uses click events to display
the selected team's trophy details and players dynamically.

Note: The player lists are a basic project dataset and can be edited in `script.js`.
